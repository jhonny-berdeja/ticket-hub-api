# ticket-hub-api

Este proyecto es el backend de la ticketera `ticket-hub`.

Las convenciones de desarrollo de los workflows de GitHub Actions **no** viven acá: están en el proyecto padre `jtagram`, en `.claude/infra/`.

Las convenciones de desarrollo de backend tampoco viven acá: están en `jtagram/.claude/back/`.

## Regla

Antes de desarrollar algo en este repo, asegurate de tener clonado el padre `jtagram` (como carpeta padre) para tener disponibles esas guías de convenciones.
